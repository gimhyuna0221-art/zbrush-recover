# Security and Data Safety

ZBrush recovery files may contain proprietary character/model data.

- Keep recovery analysis local whenever possible.
- Do not publish `.zpr` or `.ztl` files from clients or employers without permission.
- Redact usernames and local paths from logs before posting publicly when desired.
- Always preserve an untouched copy of the damaged source file.
- Binary repair scripts should write to a new output file and must not overwrite the source.

To report a security issue in the skill itself, open a GitHub issue without attaching confidential model data.
